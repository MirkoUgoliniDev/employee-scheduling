# Consolidati

Documenti **aggiornati e validi adesso**. Sono la fonte di verità: se un file qui contraddice
un altro documento della cartella `docs/`, vale quello che sta qui.

## Regola della cartella

- Qui dentro **solo documenti mantenuti**, che descrivono come stanno le cose oggi.
- I diari di lavoro, gli handoff datati e i rapporti di analisi restano in `docs/` e non si
  toccano più: sono cronaca, non istruzioni.
- Quando qualcosa cambia nel codice, si aggiorna il documento consolidato **nello stesso
  commit**. Un file qui che descrive uno stato superato è peggio di un file mancante, perché
  chi lo legge si fida.
- Ogni documento apre dichiarando la data a cui è aggiornato.
